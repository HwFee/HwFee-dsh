Generated by `node market/compare-published.mjs --write`.

Compares the tarball on npm for each package's published version against `npm pack`
of the current tree, file by file, by SHA-256. This is the question a release has to
answer: what would a user receive that they do not already have?

A file can appear here while `git status` shows it clean — committed but never
published. That is a release-scope difference, not an uncommitted edit, and the
last column separates the two.

## Line-ending verification · 2026-10-24

The three changed files above are byte differences from CRLF normalization. Direct comparisons of the original npm tarball (theme) and the npm-installed copy (system-fonts) against the workspace produce identical text after replacing CRLF with LF: theme client/client.js has 89 CRLF sequences in npm and 0 locally; theme README.md has 121 and 0; system-fonts lib/font-metadata.js has 149 and 0. No source behaviour difference was found in these comparisons. The original uploaded tarballs, rather than a later pack of the normalized checkout, were used for the GitHub Releases.
