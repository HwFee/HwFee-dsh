## Paths that are known not to work

`git+https://…git#<sha>&path:/plugins/<name>` — pnpm installs the repository
**root** for a git dependency and ignores `&path:`. This repository's root is not
a plugin, so the install lands the whole monorepo with a placeholder manifest, or
fails outright. A git-installable plugin needs the repo root to *be* the plugin.
